# .teo
A programming language written in Python.

## Status
Early development.

## Setup
```bash
pip install -e .
```

## Running
```bash
teo file_name.teo
```

## Features
- `console_log = <output>`
- <`variable_name> = <value>`
- var <`local_variable_name> = <value>`
- separate statements with \';\' or new line

## Help
run  `teo -h` or `teo --help`
